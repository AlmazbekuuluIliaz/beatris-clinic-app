# Контракт API (источник истины)

`openapi.yaml` здесь — **каноничная версионируемая копия** контракта API Beatris.
Это первый источник истины при расхождении OpenAPI / SQL / кода (см. `AGENTS.md` §3).

- Оригинал ведётся вне репозитория (`C:/Users/Ильяз/Downloads/openapi.yaml`) и
  правится только по явному запросу. Здесь — синхронная копия для кода/CI/фронтенда.
- Соответствие кода контракту проверяется автотестом
  `tests/test_openapi_contract.py` (каждый путь+метод контракта обязан быть в
  `app.openapi()`; дополнительные backend-маршруты разрешены).
- Намеренные расхождения по полям задокументированы в `AGENTS.md` §6.

При изменении контракта: обнови оригинал → синхронизируй эту копию → прогони
`pytest tests/test_openapi_contract.py`.
